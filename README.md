# お薬管理

毎日の服用と在庫を記録する、スマートフォン向けのアプリです。iPhone の Safari で開いて「ホーム画面に追加」すると、普通のアプリと同じようにホーム画面から起動できます。このような、ウェブページをアプリのように使える仕組みを PWA（Progressive Web App）と呼びます。

データはサーバーには送られず、使っている端末の中（ブラウザの localStorage という保存場所）だけに保存されます。一度開けば、電波が届かない場所でも起動できます。

## できること

「今日」タブでは、今日飲むお薬が朝・昼・夜の順に並びます。「飲んだ」を押すと記録が付き、その分だけ在庫が自動で減ります。週1回のお薬は、予定の曜日を過ぎてもまだ使っていなければ「未実施」として表示され続けます。在庫が7日分を切ると、警告が表示されます。

「お薬」タブでは、登録したお薬の在庫と、あと何日分残っているかを確認できます。補充・編集・削除・並び替えもこのタブで行います。

「記録」タブでは、直近7日または30日の服用率のグラフと、予定どおり飲めた日が何日続いているか（連続達成）を確認できます。飲み忘れて記録しなかった分をあとから追加したり、記録を直したり取り消したりすることもできます。

右上の歯車からは、バックアップの書き出しと読み込み、全データの削除ができます。

## フォルダの構成

アプリを直すときに触るのは `src/` と `public/` の2つです。`dist/` はビルド（後述）で自動的に作られるので、直接は編集しません。

```
src/                 アプリのソースコード
  App.jsx            アプリ全体のまとめ役（データを持ち、各画面に渡す）
  screens/           各タブの画面（今日・お薬・記録）
  components/        入力フォームやシートなど、画面の部品
  lib/               計算やデータ保存の処理（画面とは独立していてテストできる）
    schedule.js      「今日飲むもの」と服用率・連続達成の計算
    records.js       服用の記録・在庫の増減・お薬の登録などのデータ書き換え
    storage.js       端末への保存とバックアップの形式
    medicine.js      タイミングや単位などの決まりごと、在庫日数の計算
    date.js          日付の道具
  styles.css         画面全体の見た目の設定
public/              そのまま公開されるファイル（index.html、アイコン、sw.js など）
tests/               計算処理のテスト
scripts/build.mjs    ビルドの手順
dist/                公開用のファイル一式（ビルドで作られる）
```

## 開発のしかた

あらかじめ Node.js（JavaScript をパソコンで動かすためのソフト）の 18 以上をインストールしておきます。そのうえで、このフォルダで次のコマンドを実行します。

```sh
npm install      # 必要な部品を取ってくる（最初の1回だけ）
npm run dev      # 直すたびに自動で作り直し、http://localhost:5173 で確認できる
npm test         # 計算処理のテストを実行する
npm run build    # 公開用のファイルを dist/ に作る
```

ここでいう「ビルド」とは、`src/` に分けて書いたソースコードを、ブラウザがそのまま読み込める1つのファイル（`dist/app.js`）にまとめる作業のことです。画面の見た目を決める CSS も、使っている分だけを集めて `dist/tailwind.css` にまとめます。

## 公開のしかた

`npm run build` を実行してから、`dist/` の**中身のファイル**をすべて、公開先の同じ場所に並べて置きます。フォルダごとではなく、`index.html` と同じ階層に `app.js` や `tailwind.css` が並ぶように置いてください。

ビルドのたびに、ファイルに「版番号」が書き込まれます。端末は一度読み込んだファイルを保存して使い回しますが、版番号が変わると新しいファイルを取り直すため、更新が確実に反映されます。

## データの引き継ぎ

端末への保存場所の名前（`med_app_medicines_v2` と `med_app_logs_v2`）とバックアップファイルの形式は、作り直す前の版と同じです。そのため、同じアドレスで公開すれば今までの記録がそのまま使えますし、以前に書き出したバックアップファイルも読み込めます。

## 注意

このアプリは服用の記録を助けるための道具です。服用量や飲み方については、必ず医師や薬剤師の指示に従ってください。
